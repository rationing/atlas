# Transform a rectangular atlas to a square atlas!

To use this atlas converter:

1. Install the Python library called "Pillow":

```
python3 -m pip install --upgrade pip
python3 -m pip install --upgrade Pillow
```

2. Name the atlas image file you want to transform "old-atlas.png".

3. Run ``python main.py`` in the same directory as your atlas.

4. Open your new "atlas.png" file!
