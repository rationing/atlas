# Python script for texture atlases
Transform a rectangular PNG texture
atlas to an inflated square atlas!

To use this texture atlas converter:

1. [Install Pillow](
https://github.com/python-pillow/Pillow
)

2. Name the atlas image file you 
   want to transform "old.png".

3. Run ``python main.py`` in the same
   directory as your atlas.

4. Open your new "atlas.png" and
   "numbers.png" files!
